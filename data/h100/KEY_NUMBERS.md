# KEY_NUMBERS

所有数值由 `driver/make_numbers.py` 从 `results/analysis/*.csv` 直接生成。
每张表标注了产生它的配置与 run_id 前缀。完整原始数据见压缩包。

## 0. 口径

- 拓扑:`1n8/EP8` 单机 8 卡 Direct;`2n4/EP8` 两机各 4 卡 Hybrid,与 1n8 同 EP,隔离跨机第一跳;`2n8/EP16` 两机各 8 卡 Hybrid。
- 主配置:H=7168, K=8, E=256, BF16 dispatch, balanced, uniform, `--paper-profile`(`use_fp8_dispatch=0, expert_alignment=1, num_bias=0`)。
- 百分位规则:先对每次迭代取全部 EP rank 的最大值,再在这些逐迭代关键路径值上求百分位。
- 总延迟只取自 trace-off;相位拆分只取自 trace-on;两者从不相减。
- `T_gate = pre_barrier_end - pre_barrier_begin`,即强制 barrier 本身,不是全部前置协调成本。

## 5. 受控路由偏斜(传输字节完全相同)

`ctrlz{zipf}_*`,每 token 固定 2 个不同目的 rank,只改目的地权重(Zipf 指数,rank 0 为热点)。
同一 cell 内 `bytes_total` 逐字节相同,故延迟差异与传输量无关。

`max/mean` 为最忙 rank 的字节量与均值之比,即热点强度;它是总量固定时唯一变化的东西。

| 1n8/EP8 | 128 | 30 MB | 0.0:1.04 0.6:1.86 1.2:2.84 | 23.7 | - | 29.6 | - | 37.9 | 1.60x |

| 2n8/EP16 | 1024 | 473 MB | 0.0:1.05 0.3:1.73 0.6:2.70 0.9:3.81 1.2:4.98 | 307.7 | 333.8 | 385.2 | 442.3 | 502.7 | 1.63x |
| 2n8/EP16 | 4096 | 1892 MB | 0.0:1.03 1.2:4.98 | 1048.1 | - | - | - | 1714.6 | 1.64x |

受控偏斜呈现三个稳定规律：

- **偏斜代价随消息增大而暴露。** 1n8 的 `z=1.2/z=0.0` 从 T=32 的 1.21x 单调增至 T=4096 的 2.47x；小消息主要受固定成本影响，大消息才显著暴露热点排队。
- **热点强度与延迟单调对应。** 1n8、T=1024 的热点强度从 1.04、1.39、1.85、2.33 增至 2.80 时，延迟依次为 99.3、120.9、154.4、190.2、224.3 µs；2n8 的五点曲线同样单调。
- **不同拓扑不能只按 Zipf 指数横向比较。** T=1024 时 1n8、2n4、2n8 的增幅分别为 2.26x、1.26x、1.63x，但 `z=1.2` 在 EP16 上产生 4.98 的热点强度，在 EP8 上仅约 2.80；跨机路径本身的固定成本也会稀释相对增幅。

## 12. 数据完整性

- 验收门 5690 项,落在本文引用数据上的失败 0 项。
- 标记与 Kineto 内核时长一致(判据 max(10%, 2µs));时间戳顺序无一违反;每 rank 原始记录数恰为 2N+1。
- 两节点容器镜像 ID 一致。延迟注入下 T_gate 等量增长而 payload window 不变。
- 物理检查:无带宽超过 NVLink 或端口线速;15 条延迟曲线无下降;每 token 成本无上升。3 条 TX/RX 软告警为 2.1%--2.5% 的固定控制面偏移,无硬性违规。
- 中断的 `q12_nccl_sens` 仅产生一格已通过验收的 `sensh1024_1n8_ll_t32`;它不进入当前论文表格,也不影响上述结论。
